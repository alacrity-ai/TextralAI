# Textral Sandbox Frontend — Implementation Steps

> Companion to `docs/v3/TEXTRAL_SANDBOX_FRONTEND_DESIGN.md`. Concrete,
> ordered steps. A dev follows this end-to-end and at the close has
> shipped the finished sandbox: a Vite + React 19 + TypeScript app at
> `apps/sandbox/` that talks to a V3 deployment (self-host or CF) and
> gives an operator the QueryBench / Compare / Ingest / Admin
> surfaces the design doc described.
>
> **No open questions.** Where the design doc left a choice open,
> this document picks one and stays with it.
>
> ## Status
>
> Not started. Steps below describe the as-shipped target.
>
> Path is dependency-sound: every step's prerequisites are completed
> by earlier steps. The 23 steps split into three milestones:
>
> - **M1 — usable core (Steps 1–11)**: ~5 days. ApiKey gate, namespace
>   picker, ingest, QueryBench, history. Sandbox earns its keep.
> - **M2 — comparison + inspection tier (Steps 12–18)**: ~5 days.
>   Compare, ProviderKeys, NamespaceList, DocumentInspector, Admin,
>   SSE, generated types.
> - **M3 — production-shape build + ship (Steps 19–23)**: ~2 days.
>   Dockerfile, compose service, CI lane, docs.

## At completion, you will have

- `apps/sandbox/` — a new pnpm workspace member, built with Vite 6 +
  React 19 + TypeScript 5, sharing tsconfig and lockfile with the
  rest of the monorepo.
- A polished AppShell (lifted from `apps/frontend/`) with command
  palette (⌘K), help overlay (?), toast + confirm dialogs, and a
  resizable-pane primitive. Roughly 600 LoC lifted unchanged from
  the V2 frontend.
- An API-key auth gate that reads/validates the key against
  `/v1/me` and persists it in `localStorage`. No login flow, no
  multi-user assumptions — single operator, single tenant.
- An API client (`src/api/client.ts`) that adds the
  `X-Textral-Api-Key` header, unwraps the `{error: {…}}` envelope on
  failure, and supports SSE streaming for `/v1/query?stream=sse`.
- The five M1 pages (Ingest, QueryBench, QueryHistory) and the four
  M2 pages (Compare, ProviderKeys, NamespaceList, DocumentInspector,
  Admin) wired into a single router shell.
- The two highest-value lifted components — `AnswerAuditDrawer` and
  `SourcePanel` — embedded in QueryBench so every query reveals its
  full audit trail and chunk-level provenance with one click.
- Generated TypeScript types via `openapi-typescript`, replacing the
  hand-typed `api/types.ts` from M1.
- A multi-stage Docker build, wired into the self-host
  `docker-compose.yml` as the `sandbox` service so
  `make selfhost-up` brings it up alongside the api.
- CI coverage: `pnpm --filter @textral/sandbox build` runs in the
  Node lane of `.github/workflows/ci.yml`. Failure is a release
  blocker.
- `README.md` and `docs/SELF_HOSTING.md` updated to point operators
  at `http://localhost:5173` after `make selfhost-up`.

## What this implementation specifically does NOT do

- **No customer-facing chrome.** Everything is operator-flavored:
  monospace where appropriate, dense layouts, no marketing.
- **No multi-user state.** Single API key, single tenant, single
  operator. Adding multi-tenant testing is a follow-up.
- **No SSO / OAuth / login flow.** Paste-your-key gate only.
- **No mobile responsive.** Desktop-only.
- **No i18n.** English-only, no string-extraction wiring.
- **No tests in M1.** Smoke tests are optional in M3 if there's
  appetite (Vitest + React Testing Library); the sandbox is
  small enough that the cf-pool + Node-pool integration tests on
  the api side give us most of what tests would.
- **No "experiment runs" persistence.** The sandbox uses
  `query_events` history for replay; no separate experiment store.
- **No replacement for `/docs` (Scalar).** Scalar is the API
  reference; this is the playground. The help overlay links to
  `/docs` for spec lookup.

## Step 3 — API-key auth (gate + context + validation)

### 3.1 `src/auth/ApiKeyContext.tsx`

Holds the current key. Reads/writes `localStorage.textral_api_key`.

```tsx
import { createContext, useContext, useState, ReactNode } from 'react';

const KEY_STORAGE = 'textral_api_key';

interface ApiKeyState {
  key: string | null;
  setKey: (k: string | null) => void;
}

const ApiKeyContext = createContext<ApiKeyState | null>(null);

export function useApiKey(): ApiKeyState {
  const ctx = useContext(ApiKeyContext);
  if (!ctx) throw new Error('useApiKey must be used within ApiKeyProvider');
  return ctx;
}

export function ApiKeyProvider({ children }: { children: ReactNode }) {
  const [key, setKeyState] = useState<string | null>(
    () => localStorage.getItem(KEY_STORAGE),
  );
  const setKey = (k: string | null) => {
    if (k) localStorage.setItem(KEY_STORAGE, k);
    else localStorage.removeItem(KEY_STORAGE);
    setKeyState(k);
  };
  return (
    <ApiKeyContext.Provider value={{ key, setKey }}>
      {children}
    </ApiKeyContext.Provider>
  );
}
```

### 3.2 `src/auth/ApiKeyGate.tsx`

Modal that blocks UI when no key is set. Validates the pasted key
via `GET /v1/me` before storing.

```tsx
import { useState } from 'react';
import { useApiKey } from './ApiKeyContext.js';
import { Button, Input, Card } from '../components/ui/index.js';

export function ApiKeyGate({ children }: { children: React.ReactNode }) {
  const { key, setKey } = useApiKey();
  const [pending, setPending] = useState('');
  const [err, setErr] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);

  if (key) return <>{children}</>;

  async function submit() {
    setBusy(true);
    setErr(null);
    try {
      const res = await fetch('/v1/me', {
        headers: { 'x-textral-api-key': pending },
      });
      if (!res.ok) {
        setErr(res.status === 401 ? 'Invalid API key' : `Server returned ${res.status}`);
        return;
      }
      setKey(pending);
    } catch (e) {
      setErr(`Network error: ${(e as Error).message}`);
    } finally {
      setBusy(false);
    }
  }

  return (
    <div className="apikey-gate">
      <Card>
        <h2>Paste your Textral API key</h2>
        <p>
          Format: <code>tx_live_...</code>. Stored in localStorage on
          this machine only. Run <code>make selfhost-seed-cookbook</code>
          (or <code>make seed-self-host</code>) to mint one.
        </p>
        <Input
          type="password"
          value={pending}
          onChange={(e) => setPending(e.target.value)}
          placeholder="tx_live_..."
          autoFocus
        />
        {err && <p className="error">{err}</p>}
        <Button onClick={submit} disabled={!pending || busy}>
          {busy ? 'Validating…' : 'Continue'}
        </Button>
      </Card>
    </div>
  );
}
```

## Step 4 — API client + types

### 4.1 `src/api/client.ts`

```ts
import { z } from 'zod';

const TextralErrorSchema = z.object({
  error: z.object({
    code: z.string(),
    message: z.string(),
    request_id: z.string().optional(),
    details: z.unknown().optional(),
  }),
});

export class TextralApiError extends Error {
  constructor(
    public readonly status: number,
    public readonly code: string,
    message: string,
    public readonly requestId?: string,
    public readonly details?: unknown,
  ) {
    super(message);
  }
}

function getKey(): string {
  const k = localStorage.getItem('textral_api_key');
  if (!k) throw new Error('API key missing — gate should have prevented this');
  return k;
}

export async function api<T = unknown>(
  method: 'GET' | 'POST' | 'PATCH' | 'DELETE' | 'PUT',
  path: string,
  body?: unknown,
  init?: RequestInit,
): Promise<T> {
  const headers: Record<string, string> = {
    'x-textral-api-key': getKey(),
    ...((init?.headers as Record<string, string>) ?? {}),
  };
  if (body !== undefined && !(body instanceof FormData)) {
    headers['content-type'] = 'application/json';
  }
  const res = await fetch(path, {
    method,
    headers,
    body:
      body === undefined
        ? undefined
        : body instanceof FormData
        ? body
        : JSON.stringify(body),
    ...init,
  });
  if (res.status === 204) return undefined as T;
  const text = await res.text();
  if (!res.ok) {
    const parsed = TextralErrorSchema.safeParse(text ? JSON.parse(text) : {});
    if (parsed.success) {
      throw new TextralApiError(
        res.status,
        parsed.data.error.code,
        parsed.data.error.message,
        parsed.data.error.request_id,
        parsed.data.error.details,
      );
    }
    throw new TextralApiError(res.status, 'UNKNOWN', text);
  }
  return text ? (JSON.parse(text) as T) : (undefined as T);
}
```

## Step 5 — Namespace context + picker

### 5.1 `src/context/NamespaceContext.tsx`

Single active namespace per session; persisted to `localStorage`.

```tsx
import { createContext, useContext, useState, useEffect, ReactNode } from 'react';
import type { Namespace } from '../api/types.js';
import { api } from '../api/client.js';

interface NamespaceState {
  list: Namespace[];
  active: Namespace | null;
  setActiveBySlug: (slug: string) => void;
  refresh: () => Promise<void>;
}
const NamespaceContext = createContext<NamespaceState | null>(null);
export const useNamespace = () => {
  const c = useContext(NamespaceContext);
  if (!c) throw new Error('useNamespace must be used within NamespaceProvider');
  return c;
};

export function NamespaceProvider({ children }: { children: ReactNode }) {
  const [list, setList] = useState<Namespace[]>([]);
  const [activeSlug, setActiveSlug] = useState<string | null>(
    () => localStorage.getItem('textral_active_namespace'),
  );

  const refresh = async () => {
    const r = await api<{ data: Namespace[] }>('GET', '/v1/namespaces');
    setList(r.data);
    if (!activeSlug && r.data.length > 0) {
      setActiveSlug(r.data[0]!.slug);
      localStorage.setItem('textral_active_namespace', r.data[0]!.slug);
    }
  };
  useEffect(() => { void refresh(); }, []);

  const active = list.find((n) => n.slug === activeSlug) ?? null;
  const setActiveBySlug = (slug: string) => {
    setActiveSlug(slug);
    localStorage.setItem('textral_active_namespace', slug);
  };

  return (
    <NamespaceContext.Provider value={{ list, active, setActiveBySlug, refresh }}>
      {children}
    </NamespaceContext.Provider>
  );
}
```

## Step 7 — Ingest page + IngestStreamLog

### 7.1 `src/components/IngestStreamLog.tsx`

Polls `/v1/ingestion-jobs/{id}` every 1.5s; renders a stage strip.

```tsx
import { useEffect, useState } from 'react';
import type { IngestionJob } from '../api/types.js';
import { api } from '../api/client.js';

export function IngestStreamLog({ jobId }: { jobId: string }) {
  const [job, setJob] = useState<IngestionJob | null>(null);
  const [err, setErr] = useState<string | null>(null);

  useEffect(() => {
    let stopped = false;
    async function tick() {
      while (!stopped) {
        try {
          const r = await api<IngestionJob>('GET', `/v1/ingestion-jobs/${jobId}`);
          setJob(r);
          if (r.status === 'completed' || r.status === 'failed') break;
        } catch (e) {
          setErr((e as Error).message);
          break;
        }
        await new Promise((rs) => setTimeout(rs, 1500));
      }
    }
    void tick();
    return () => { stopped = true; };
  }, [jobId]);

  if (err) return <div className="error">{err}</div>;
  if (!job) return <div>Starting…</div>;
  return (
    <div className="ingest-log">
      <div>job_id: <code>{job.id}</code></div>
      <div>status: {job.status}</div>
      <div>stage: {job.current_stage ?? '-'}</div>
      <div>attempts: {job.attempt_count}</div>
      {job.error_code && (
        <div className="error">
          {job.error_code}: {job.error_message}
        </div>
      )}
    </div>
  );
}
```

```tsx
async function ingestFlow(file: File, opts: IngestOpts): Promise<string> {
  const doc = await api<{ id: string }>('POST',
    `/v1/namespaces/${opts.namespace}/documents`,
    { title: opts.title, doc_type: 'passage' });
  const upload = await api<{ upload_id: string; url: string }>('POST',
    `/v1/documents/${doc.id}/uploads`,
    { content_type: file.type || 'text/markdown', size_bytes: file.size });
  // Worker-proxied upload: PUT carries the api key header too.
  const putRes = await fetch(upload.url, {
    method: 'PUT',
    headers: {
      'content-type': file.type || 'text/markdown',
      'x-textral-api-key': localStorage.getItem('textral_api_key')!,
    },
    body: file,
  });
  if (!putRes.ok) throw new Error(`upload PUT failed: ${putRes.status}`);
  const fin = await api<{ version_id: string }>('POST',
    `/v1/documents/${doc.id}/uploads/${upload.upload_id}/finalize`, {});
  const ing = await api<{ job_id: string }>('POST',
    `/v1/documents/${doc.id}/ingest`,
    {
      version_id: fin.version_id,
      embedding: { provider: 'openai', model: 'text-embedding-3-large',
                   dimensions: 1536, provider_key_ref: opts.providerKeyLabel },
      chunking: { profile: opts.chunkingProfile, target_tokens: opts.targetTokens,
                  overlap_tokens: opts.overlapTokens },
      mode: opts.mode,
    });
  return ing.job_id;
}
```

and on submit fires `ingestFlow()` then mounts

## Step 17 — SSE streaming toggle in QueryBench

### 17.1 Implement `src/api/sse.ts`

```ts
export async function* readSSE(
  res: Response,
): AsyncGenerator<{ event: string; data: string }> {
  if (!res.body) return;
  const reader = res.body.getReader();
  const decoder = new TextDecoder();
  let buf = '';
  for (;;) {
    const { value, done } = await reader.read();
    if (done) break;
    buf += decoder.decode(value, { stream: true });
    let idx;
    while ((idx = buf.indexOf('\n\n')) >= 0) {
      const block = buf.slice(0, idx);
      buf = buf.slice(idx + 2);
      let event = 'message';
      const data: string[] = [];
      for (const line of block.split('\n')) {
        if (line.startsWith('event:')) event = line.slice(6).trim();
        else if (line.startsWith('data:')) data.push(line.slice(5).trim());
      }
      yield { event, data: data.join('\n') };
    }
  }
}
```

| Document list (per namespace) | `GET /v1/namespaces/{slug}/documents?limit=&cursor=` | `{ data: Document[], next_cursor: string \| null }` — newest-first, soft-deleted excluded, cursor by `created_at`. Powers DocumentInspector's browse view. Tests in `apps/api/test/documents-list.test.ts`. |
| Chunk list (per document) | `GET /v1/documents/{id}/chunks?limit=&cursor=&artifact_type=&version_id=` | `{ data: Chunk[], next_cursor: string \| null }` — ascending by `ord`, scoped to current_version_id by default; cursor is opaque ord.
