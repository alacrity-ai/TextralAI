# Sample data

Public-domain texts on the Library of Alexandria, written for the
SDK cookbook. Used by every example in this directory; vendored
into the package so users can `npm install @textral/sdk` and run
the examples without external downloads.

The same files live under `packages/sdk-python/examples/data/` —
keeping the corpus identical means the cookbook scripts can be
read side-by-side across both languages without surprise.
